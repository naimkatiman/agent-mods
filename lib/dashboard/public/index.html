          Assumptions

          What agents decided without asking you. Your verdict goes back to the session that logged it. Mark one wrong with a correction and it becomes a rule every agent in that repo gets at the start of each session.

          Ideas

          Side ideas agents shelved instead of chasing them. Copy an idea's prompt to start it in any session; the idea stays on the shelf until a session takes it. Drop the ones you won't do.

          Rules

          Corrections you gave when you marked an assumption wrong. Every session of every agent in that repo gets them at start, in any worktree.

          Design decisions

          Design directions you picked when an agent asked. Every agent in that repo builds with them.

          Messages

          Messages waiting in a session's agent-mods inbox. A session reads them with its next prompt (Grok with its next edit, or when it calls the briefing tool). Unread messages expire after 24 h, and a message never answers a permission prompt.

          Activity

          newest first

          Every hook event from every agent on this machine, as it happens. The last 30 minutes, at most 200 lines.

          Health

          A hook reports only when its agent does something, so an agent with nothing running, or only finished sessions, goes quiet. That is normal. A session is flagged only when it says it is working and has sent no hook for 15 minutes.

          Settings

          shared by every agent here

          Plain-talk answers

          How plainly every agent writes its final answers.

          Finish alerts

          A sound and a Windows toast when a long turn finishes. This page never repeats them.

          Clawd's hat

          A pinned hat goes on every Clawd now and on every new session. Random gives each new session its own. Naps always swap in the nightcap.

          Shades

          Clawd in terminal panes

          Hides or shows Clawd in every agent's terminal pane. Pets on this page stay.
